# Douglas Roy Schoonover

Researcher and author — Chippewa Falls–Eau Claire County, Wisconsin area.

I work on **serotype and disease groupings**, **Streptococcus pneumoniae serotypes** and the 23-serotype pneumococcal panels, **quantum medicine**, **fungal replacement therapy nomenclature**, and **vaccine and toxoid research**.
